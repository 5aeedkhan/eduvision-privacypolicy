Overview

EduVision ("we", "us", or "our") operates the EduVision mobile application (the "Service"), a smart classroom automation platform for university students and teachers. This Privacy Policy explains what data we collect, how we use it, where it is stored, and how you can manage or delete it.

Summary: EduVision collects your name, email, academic info, board images, audio recordings, PPTX files, and app activity (Q&A, announcements, attendance). Data is encrypted in transit and at rest. We do not share data with third parties for advertising. You can delete your account and data at any time.

Data We Collect

1. Personal Information

  • Name — Used to display your identity within the app and for attendance records
  • Email address — Used for authentication and account management
  • User ID — A unique identifier assigned by Firebase Authentication, used to associate your data with your account
  • Role — Student, teacher, or admin (determines which app features are available to you)

Collected: Yes  |  Shared: No  |  Purpose: App functionality, Account management  |  Encrypted: Yes  |  Deletion: Yes

2. Academic Information

  • Class ID and Section — Used to filter lectures, attendance, quizzes, and announcements relevant to your class
  • University — Optional, displayed on teacher profiles
  • Subject — Optional, used for teacher profiles and lecture categorization

Collected: Yes  |  Shared: No  |  Purpose: App functionality  |  Encrypted: Yes  |  Deletion: Yes

3. Photos and Videos

  • Board images — Captured via the camera by teachers during lecture recording. These images are used to generate PPTX presentations and are stored locally on the device and in the cloud as part of the generated PPTX file.

Collected: Yes  |  Shared: No  |  Optional: Yes (teachers choose to record)  |  Purpose: App functionality  |  Encrypted: Yes  |  Deletion: Yes

4. Audio Recordings

  • Voice/sound recordings — Recorded by teachers via the microphone during lecture recording. Audio clips are embedded inside the generated PPTX file and uploaded to Cloudflare R2 as part of the PPTX.

Collected: Yes  |  Shared: No  |  Optional: Yes (teachers choose to record)  |  Purpose: App functionality  |  Encrypted: Yes  |  Deletion: Yes

5. Files and Documents

  • PPTX lecture files — Generated presentations containing board images and embedded audio. Teachers generate PPTX files which are uploaded to Cloudflare R2. Students download PPTX files from R2 to their device's Downloads/EduVision folder.

Collected: Yes  |  Shared: No  |  Optional: Yes (teachers choose to generate, students choose to download)  |  Purpose: App functionality  |  Encrypted: Yes (in transit and at rest)  |  Deletion: Yes

6. App Activity

  • Questions and answers — Posted by students and teachers in the Q&A section
  • Announcements — Created by teachers and admins for their classes
  • Attendance records — Created when students scan QR codes (includes student name, class, subject, date, and status)
  • Quiz responses — Student answers to quizzes created by teachers

Collected: Yes  |  Shared: No  |  Purpose: App functionality  |  Encrypted: Yes  |  Deletion: Yes

7. Account Deletion Requests

  • Deletion request data — When you request account deletion, your name, email, and role are stored temporarily in a deletion request queue in Firestore until the admin processes your request. This data is deleted once the request is completed.

How We Use Your Information

  • To authenticate users and manage accounts (email, name, user ID)
  • To provide class-specific content including lectures, announcements, Q&A, and quizzes
  • To enable lecture digitization: board images + audio recordings are used to generate PPTX presentations
  • To store and share PPTX files via Cloudflare R2 so students can download them
  • To track attendance via QR code scanning
  • To facilitate communication between teachers and students through Q&A and announcements
  • To process password reset requests via email
  • To process account deletion requests

Local Storage (On-Device)

EduVision stores the following data locally on your device using the Hive database and the file system:

Data Location Persists after uninstall?
User profile cache (name, email, role, academic info) App private storage (Hive) No
Board images App private storage No
Audio recordings App private storage No
QR code images Temporary cache No
PDF attendance reports Temporary cache No
PPTX lecture files (teacher-generated or student-downloaded) Public Downloads/EduVision folder Yes

Files in the app's private storage and the local Hive database are removed when you uninstall the app. PPTX files saved in the Downloads/EduVision folder remain after uninstallation and can be manually deleted by the user at any time using a file manager.

Cloud Storage and Security

All cloud data is stored securely using the following services:

Service What it stores Encryption
Firebase Authentication Email, password (hashed), user ID In transit (HTTPS/TLS) + at rest
Cloud Firestore User profiles, lecture metadata, attendance records, Q&A, announcements, quiz data In transit (HTTPS/TLS) + at rest
Cloudflare R2 Generated PPTX lecture files (containing board images + embedded audio) In transit (HTTPS/TLS) + at rest
  • All data is transmitted over HTTPS/TLS encryption
  • Passwords are hashed by Firebase Authentication (we never see or store raw passwords)
  • Firestore data is encrypted at rest by Google Cloud
  • Cloudflare R2 provides encryption at rest for stored objects

Third-Party Services

EduVision uses the following third-party services as data processors:

  • Google Firebase — Provides authentication, database storage (Firestore), and cloud infrastructure. Firebase processes your email, name, user ID, and app data to provide these services. Google's privacy policy →
  • Cloudflare R2 — Provides cloud object storage for generated PPTX lecture files. When a teacher generates a PPTX, the file is uploaded to R2 so students can download it. Cloudflare processes the PPTX file data (which contains board images and embedded audio) to provide this storage service. Cloudflare's privacy policy →
  • Google Fonts — The app downloads the Poppins font from Google's servers for UI display. Google Fonts may receive your device's IP address when fetching fonts. Google's privacy policy →

No advertising, no tracking, no data brokers. EduVision does not use any advertising SDKs, analytics trackers, or third-party data brokers. We do not sell or rent your data.

Data Sharing

We do not share your personal data with any third parties for advertising or commercial purposes. Your data is only accessible to:

  • You — your own data and content
  • Teachers in your class — class-related content (lectures, announcements, attendance)
  • Admins — for account management and user support

The app allows you to share QR codes, PDF attendance reports, and PPTX lecture files via the Android share sheet (e.g., WhatsApp, Gmail, etc.). When you use this feature, the selected file is sent directly to the app you choose. We do not control or have access to what you share or with whom.

Data Retention and Deletion

Account Deletion

You can request full account and data deletion at any time:

  • Use the in-app "Delete My Account" button in Settings → Profile
  • This sends a deletion request to the admin
  • The admin permanently removes your account, profile data, and associated content from Firebase and Cloudflare R2 within 48 hours
  • Alternatively, email muhammads4eedkhan@gmail.com with your deletion request

Partial Data Deletion (Without Deleting Account)

You can delete certain data without deleting your entire account:

  • Teachers can delete their own lectures at any time. This removes the lecture's board images, audio recordings, and the PPTX file from Cloudflare R2 and Firestore immediately.
  • Teachers/admins can delete announcements they have created
  • Students can delete downloaded PPTX files from the Downloads/EduVision folder using a file manager
  • All users can update their profile information (name, university, subject) within the app

Data Retention Period

Your data is retained for as long as your account is active. Once you request deletion, all associated data is removed within 48 hours. Deletion request metadata is deleted once the request is processed.

Your Rights

  • Access — You can view your data within the app at any time
  • Deletion — You can request full account deletion via the in-app "Delete My Account" button or by email. The admin will process your request within 48 hours.
  • Partial deletion — You can delete specific lectures, announcements, and downloaded files without deleting your account
  • Correction — You can update your profile information (name, university, subject) within the app
  • Permission control — You can grant or revoke camera, microphone, and storage permissions at any time in your device Settings

Children's Privacy

EduVision is designed for university-level students and educators (age 18+). We do not knowingly collect data from children under 13. If you believe a child has provided us with personal information, please contact us at muhammads4eedkhan@gmail.com for immediate deletion.
